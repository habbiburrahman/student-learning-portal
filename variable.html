Variable in Java Script




In JavaScript, a variable is a named place to store data, such as a number, string, or object.
There are three keywords used to declare variables:



let age = 20;
const name = "John";
var city = "London";

let — use when the value may change.




let score = 10;
score = 20;

const — use when the variable should not be reassigned.




const pi = 3.14;

var — older way of declaring variables; generally prefer let and const in modern JavaScript.



For example:h3>

let studentName = "Alex";
let age = 18;
const school = "ABC School";

console.log(studentName);
console.log(age);
console.log(school);
