Flexbox in CSS




Flexbox, short for Flexible Box Layout, is a powerful CSS layout system used to arrange and align elements on a webpage. It makes it easier to create layouts where elements need to be placed in a row or column. Flexbox is commonly used for navigation bars, buttons, cards, menus, images, and responsive website layouts.


Flexbox works with a parent element and its child elements. When we apply display: flex; to the parent element, it becomes a flex container, and its direct children become flex items. Flexbox provides several properties to control the direction, alignment, spacing, and size of these items.



Important Flexbox Properties


1. display: flex


The display: flex property is used to enable Flexbox on a container.
.container {
display: flex;
}
The element becomes a flex container, and its direct child elements become flex items.



2. flex-direction


The flex-direction property specifies the direction in which flex items are arranged.
.container {
display: flex;
flex-direction: row;
}
The main values are:

flex-direction: row;
flex-direction: row-reverse;
flex-direction: column;
flex-direction: column-reverse;
row arranges items horizontally, while column arranges them vertically.



3. justify-content


The justify-content property controls the alignment of flex items along the main axis.
.container {
display: flex;
justify-content: center;
}

Common values include:

justify-content: flex-start;
justify-content: flex-end;
justify-content: center;
justify-content: space-between;
justify-content: space-around;
justify-content: space-evenly;

For example:
.container {
display: flex;
justify-content: space-between;
}
This distributes available space between the items..





4. align-items


The align-items property controls the alignment of flex items along the cross axis.

.container {
display: flex;
align-items: center;
}
Common values are:
align-items: flex-start;
align-items: flex-end;
align-items: center;
align-items: stretch;

It is commonly used to vertically center elements.



5. gap


The gap property creates space between flex items.

.container {
display: flex;
gap: 20px;
}

This creates a 20px gap between the items.
