Introduction of CSS




CSS stands for Cascading Style Sheets and it is a stylesheet language used to design and style HTML webpages. While HTML is used to create the structure and content of a webpage, CSS is used to control how that content looks on the screen. With CSS, developers can change the color, font, size, spacing, alignment, borders, background, position, and overall appearance of HTML elements. CSS is one of the most important technologies in web development and is commonly learned after HTML. It helps transform a simple HTML page into an attractive, professional, and user-friendly website.



HTML uses tags written inside angle brackets, such as p, h1, img, and a, to define different types of content. Most HTML elements have an opening tag and a closing tag, while some elements, such as img and br, do not require a closing tag. HTML can be used to create headings, paragraphs, lists, tables, forms, buttons, images, links, audio, and videos. Headings can be created using h1 to h6, while the p tag is used for paragraphs. Lists can be created using ordered and unordered list tags, and tables can be created using tags such as table, tr, th, and td. HTML forms are useful for collecting information from users through text boxes, passwords, radio buttons, checkboxes, drop-down menus, and buttons.



CSS works by applying style rules to HTML elements. A CSS rule generally consists of a selector, a property, and a value. The selector specifies which HTML element should be styled, while the property defines what aspect of the element should be changed and the value specifies how it should be changed. For example, color: blue; changes the text color to blue, while font-size: 20px; changes the size of the text. CSS can be applied to headings, paragraphs, images, links, buttons, tables, forms, navigation bars, cards, and almost every visible element on a webpage.



There are three main ways to apply CSS to an HTML document: Inline CSS, Internal CSS, and External CSS. Inline CSS is written directly inside an HTML element using the style attribute. Internal CSS is written inside the <>style> tag, usually within the <>head> section of an HTML document. External CSS is written in a separate .css file and connected to HTML using the <>link> tag. External CSS is widely used in larger websites because one CSS file can be used to style multiple HTML pages. It also makes the project easier to maintain and update.


CSS provides many useful properties for designing webpages. The color property is used to change text color, while background-color changes the background color of an element. The font-size property controls the size of text, and font-family specifies the type of font. Properties such as margin and padding are used to create space around and inside elements. The border property adds borders, while width and height control the size of elements. CSS also provides properties such as text-align, line-height, border-radius, box-shadow, and opacity to improve the visual appearance of webpages.
