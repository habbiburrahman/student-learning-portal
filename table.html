HTML TABLE



NOTE:-HTML (HyperText Markup Language) uses tags to create and structure the content of a webpage. A tag tells the browser what an element is, such as a heading, paragraph, image, link, table, form, etc.


An HTML table is an important element used to display information in a structured and organized form on a webpage. It arranges data into rows and columns, making large amounts of related information easier for users to read, understand, and compare. Tables are commonly used on websites for displaying student marks, class timetables, employee records, product details, price lists, examination schedules, attendance records, and other types of tabular information. An HTML table is created using the <>table> tag, which acts as the main container for all the rows and cells of the table. Inside the <>table> element, the <>tr> tag is used to create a table row. Each row can contain heading cells or data cells. The <>th> tag is used to define a table heading, while the <>td> tag is used to define normal table data. For example, a student table can contain headings such as Name, Roll Number, Course, and Marks, with each student's information displayed in a separate row.



The basic structure of an HTML table is simple and easy to understand. The <>table> tag starts and ends the table, the <>tr> tag creates each row, and the <>th> and <>td> tags create cells inside those rows. The <>th> element is normally used for headings because browsers generally display heading text in a bold style and center it by default. The <>td> element is used for the actual information or data. A table can contain multiple rows and columns depending on the amount of information that needs to be displayed. For example, a college website can create a table containing student names, roll numbers, departments, semester numbers, and marks. Each student can be represented by one row, while each type of information can be represented by a separate column. This makes the information clear and properly organized.



HTML tables also support the border concept, although modern websites generally use CSS to create and control table borders. CSS provides much better control over the appearance of tables. Developers can use CSS properties such as border, padding, margin, text-align, background-color, font-size, and width to improve the design of a table. CSS can also be used to create different background colors for headings, add spacing between cells, change text alignment, and make tables more attractive. For example, a table heading can have a different background color from the data rows so that users can easily identify the column names. The border-collapse property is commonly used to combine table borders into a single border, giving the table a cleaner appearance.



HTML also provides the colspan and rowspan attributes for creating more advanced tables. The colspan attribute is used when one cell needs to cover two or more columns. It is useful when creating headings that apply to multiple columns. The rowspan attribute is used when one cell needs to cover two or more rows. These attributes are especially useful for creating complex tables such as examination schedules, class timetables, result sheets, and other structured data. For example, a college timetable may use rowspan to show a subject that continues for multiple periods, while colspan can be used for a heading that covers several days or subjects.



A table can also contain different types of data, including text, numbers, links, and even images. Developers can place links inside table cells using the <>a> tag and images using the <>img> tag. This makes HTML tables flexible enough to display different kinds of information together. For example, an online shopping website may use a table to display product names, product images, prices, available quantities, and links to product pages. Similarly, a student learning portal can use tables to display course information, assignment details, examination schedules, or student results.
