Grid in CSS




CSS Grid is a powerful CSS layout system used to arrange elements into rows and columns. It is especially useful for creating structured web page layouts such as course cards, image galleries, dashboards, menus, and study portals. Unlike Flexbox, which mainly works in one direction (row or column), Grid can control both rows and columns at the same time.


1. Basic Grid


.container {
display: grid;
}

The display: grid property makes an element a Grid Container, and its child elements become Grid Items.



2. Creating Columns/h3>

.container {
display: grid;
grid-template-columns: 1fr 1fr 1fr;
}

This creates 3 equal columns.



3. grid-template-columns


It defines the number and size of columns.

.container {
display: grid;
grid-template-columns: 200px 300px 200px;
}

You can also use fr:

grid-template-columns: 1fr 2fr 1fr;

Here, the middle column gets twice as much space as the first and third columns..





4. grid-template-rows


It defines the height of rows.

.container {
display: grid;
grid-template-rows: 100px 200px;
}



5. gap


The gap property creates space between rows and columns.

.container {
display: grid;
gap: 20px;
}

You can separately set:

row-gap: 20px;
column-gap: 30px;
