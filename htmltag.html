HTML Tags



NOTE:-HTML (HyperText Markup Language) uses tags to create and structure the content of a webpage. A tag tells the browser what an element is, such as a heading, paragraph, image, link, table, form, etc.



In any tag where both these symbols (<>) are written together, you have to write only (<) out of these. example <,,,> is right <>,,,> is wrong.


1. <>html> — Root Tag


The <>html> tag is the root element of an HTML document. All other HTML elements are generally written inside it.



2. <>head> — Information Section


The <>head> tag contains information about the webpage that is not directly displayed as page content. It can contain the title, CSS links, metadata, etc.



3. <>body> — Visible Content


The <>body> tag contains the main visible content of a webpage, such as headings, paragraphs, images, links, tables, and forms.



4. <>h1> — Main Heading


The <>h1> tag is used for the main or most important heading of a webpage. HTML provides headings from <>h1> to <>h6>.



5. <>p> — Paragraph


The <>p> tag is used to create a paragraph of text.



6. <>a> — Hyperlink


The tag is used to create links to other webpages, files, sections, or websites. The href attribute specifies the destination.



7. <>img> — Image


The <>img> tag is used to display images on a webpage. It commonly uses src for the image location and alt for alternative text.



8. <>div> — Container


The <>div> tag is a container used to group HTML elements. It is very commonly used with CSS to design webpage layouts.



9. <>ul> — Unordered List


The <>ul> tag creates a bullet-point list. Each item is written using the <>li> tag.



10. <>form> — Form


The <>form> tag is used to create a form for collecting user information, such as names, email addresses, passwords, and other data.
