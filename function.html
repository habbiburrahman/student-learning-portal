Function in Java Script




A function in JavaScript is a block of code that is used to perform a specific task. A function can be called whenever we need to execute that task.



Syntax:


function functionName() {
// code
}



Example:


function greet() {
console.log("Hello World!");
}

greet();



Output:


Hello World!





Function with Parameters:


Parameters allow us to pass values to a function.


function add(a, b) {
console.log(a + b);
}

add(10, 20);


Output:


30




Function with Return:


function multiply(a, b) {
return a * b;
}

let result = multiply(5, 4);
console.log(result);


Output:


20


Main Parts of a Function:


function → keyword used to create a function.
Function name → name given to the function.
Function body → code executed by the function.
return → sends a value back from the function.
Function call → used to execute the function.
